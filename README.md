# Pulse of Night — 5일차 웹 프로토타입

팀 프로젝트 「Pulse of Night」(1인칭 서바이벌 호러) 기획서의 5일차 한 근무를 브라우저에서 도는 탑다운 그레이박스로 옮긴 검증용 프로토타입입니다.

- 플레이: https://hawsung.github.io/PulseOfNightTest/
- 조작: WASD 이동 · Shift 달리기 · F 손전등 · E/오른쪽 클릭 태블릿 · Space/클릭 촬영 · 1층 경비실 단말기(Enter)에서 퇴근
- 플레이 기록은 방문자 브라우저에만 남고 어디에도 전송되지 않습니다.
