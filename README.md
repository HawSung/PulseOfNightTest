# Pulse of Night — 7일 완전판 그레이박스 시뮬레이터

팀 프로젝트 「Pulse of Night」(1인칭 서바이벌 호러) 기획서의 7일 근무 전체를 브라우저에서 도는 탑다운 그레이박스로 옮긴 검증용 시뮬레이터입니다.

- 플레이: https://hawsung.github.io/PulseOfNightTest/
- 담긴 것: 8개 층, 이상현상 50건, 괴이 6종, 일차별 근무 지시·비트 30개, 신뢰도 정산(정확 +0.4 / 오보고 −1.1 / 미보고 −1.6, 일일 하한 −20), 병원 상태 A~D, 엔딩 5종
- 조작: WASD 이동 · Shift 달리기 · F 손전등 · E/오른쪽 클릭 태블릿 · Space/클릭 촬영 · 계단에서 층 선택 · 1층 경비실 단말기(Enter)에서 퇴근
- 화면 위: 근무 속도 ×1·×2·×3, "설계 보기"(이상현상 위치·괴이 구역 표시), 아무 일차나 바로 시작
- 진행은 일차 단위로 방문자 브라우저에만 저장되고 어디에도 전송되지 않습니다.
- 5일차 단일 검증판(v1): https://hawsung.github.io/PulseOfNightTest/v1/
